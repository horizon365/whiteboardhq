### Summary
Designed for interactive sessions, Butter embeds whiteboards, video calls, docs, polls, and session agendas in one tool.

### Details
Butter combines real-time whiteboard embedding (e.g. Miro/Mural), video conferencing, session planning agenda tools, and post-session recap exports in one seamless workshop environment. 

### Website URL
https://butter.us

### What is it?
An online session and workshop platform that facilitates interactive whiteboard collaboration along with embedded video, docs, and agenda tools. 

### How to use it
Create a session/room, add Butterboard (their whiteboard embed) or integrate tools (Miro, Google Docs), launch session, collaborate live, run agenda, then export recap. 

### Key features
- Built-in session planner/agenda
- Embedded whiteboard tools (Butterboard or integrations)
- Live video, chat, polls, docs in one UI
- Session recaps including chat, logs, notes, whiteboard content
- Integrations: Slack, Google Calendar, Miro, etc. 

### Use cases
- Facilitated remote workshops and training
- Team meetings with live collaboration + presentation
- Interactive client sessions or webinars
- Hybrid learning or coaching sessions

### FAQ
**Q**: Does Butter include its own whiteboard?  
**A**: Yes—it provides a native Butterboard and also supports embedding tools like Miro or Mural.   
**Q**: Are session recordings/export supported?  
**A**: Yes—session recaps include shared materials, logs, polls, and board content.
