### Summary
Real‑time collaborative visual canvas tied directly into ClickUp workspace, enabling seamless idea-to-task conversion and team alignment.

### Details
ClickUp Whiteboards 3.0 brings a responsive, fast interface with AI‑powered visuals, templates, touch support, and deeper integration within ClickUp’s task and docs ecosystem. 

### Website URL
https://clickup.com/features/whiteboards

### What is it?
A native whiteboard tool embedded in ClickUp that enables teams to brainstorm visually and immediately convert board items into ClickUp tasks. 

### How to use it
Create a whiteboard via the toolbar, slash command, or hub; use shapes, sticky notes, media, and templates; collaborate live; convert items into tasks. 

### Key features
- Real-time multi-user collaboration with live cursors
- Template library and customizable templates
- AI-generated visuals on canvas
- Seamless task & doc integration
- Touch/pen support for tablets and stylus 

### Use cases
- Team brainstorming & ideation
- Sprint planning or project roadmaps
- Converting sketches into tracked tasks
- Client presentations embedded within tasks or docs

### FAQ
**Q**: Can free users use whiteboards?  
**A**: Free plan allows up to 3 public boards; private only on paid plans.   
**Q**: Can guests access boards without ClickUp?  
**A**: Yes—can share public board links view-only or editable depending on permissions.
