### Summary
  A free and instant collaborative whiteboard that runs in the browser.

### Details
  tldraw opens directly in the browser with an infinite canvas and a clean, hand-drawn visual style. It includes freehand drawing, geometric shapes, text, arrows, and sticky notes, and supports real-time multiplayer collaboration through a shared board link. No account is required to start, and the tool works on desktop, tablet, and mobile. The same canvas engine is also available as an open-source developer SDK for building custom whiteboard and canvas applications.

### Website
  [https://www.tldraw.com/](https://www.tldraw.com/)

### What is it?
  tldraw is a browser-based infinite canvas whiteboard for quick sketches, diagrams, and visual collaboration, built on an open-source canvas SDK.

### How to use it?
  Visit tldraw.com, start drawing immediately without signing in, and share the board link with others to collaborate in real time.

### Key Features
  Infinite canvas, drawing and shape tools, text and arrows, sticky notes, real-time multiplayer, no signup required, and an open-source SDK for developers.

### Use Cases
  Quick brainstorming, diagramming, sketching product ideas, teaching, and building custom canvas tools with the SDK.

### FAQ
  Is tldraw free? Yes, the web whiteboard at tldraw.com is free to use. Do I need an account? No, you can start drawing instantly without signing up.
