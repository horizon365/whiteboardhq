### Summary
  An online diagramming and whiteboard tool for visual teamwork.

### Details
  Cacoo is a visual collaboration tool from Nulab used by millions of people worldwide. It supports diagramming with flowcharts, wireframes, mind maps, and templates, as well as brainstorming and process visualization. Teams can edit together in real time with multi-user editing, live chat, and video calls, and can share results through comments, exports, or secure links with password protection. Integrations include Backlog, Slack, Google Drive, Google Docs, Confluence, Microsoft Teams, AWS, Box, Adobe Creative Cloud, and Microsoft Visio, and enterprise plans add SAML authentication, user provisioning, and private server hosting.

### Website

### What is it?
  Cacoo is an online diagram and whiteboard platform for turning ideas into clear visuals and collaborating on them with a team.

### How to use it?
  Create a free Cacoo account, start a diagram from a blank canvas or a template, invite collaborators to edit in real time, then share or export the finished diagram.

### Key Features
  Flowcharts, wireframes, mind maps, and templates; real-time multi-user editing; live chat and video calls; comments and secure sharing; media library and charts; broad integrations; enterprise security and private hosting options.

### Use Cases
  Process and workflow mapping, software architecture diagrams, UX wireframing, brainstorming sessions, project planning, and stakeholder presentations.

### FAQ
  Is Cacoo free? Yes, there is a free plan, with paid plans adding more features and capacity. Can I collaborate in real time? Yes, multiple users can edit diagrams together, with live chat and video calls available.
